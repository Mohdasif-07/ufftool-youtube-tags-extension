## Key Features

### 1. Rapid Tags Generator (Safe for YouTube Studio)
- Dynamic 500-Character Counter that calculates length only for selected tags, preventing the red "Tags exceed 500 characters" Studio error block.
- Multi-Select Checkboxes: Uncheck unwanted keywords before copying.
- Comma-Separated 1-Click Copy: Formatted ready to paste (Ctrl+V) directly into YouTube Studio's backend "Tags" field.
- Niche Filtering: Target keywords specifically for Gaming (Free Fire, BGMI, GTA 5), Tech & Tutorials, Finance, Lifestyle, or Shorts.

### 2. Competitor Video Tag Spy
- Open any YouTube video in your browser.
- Open the UffTool extension popup.
- Automatically extracts the hidden public backend tags used by competitors in 1 click.

### 3. High-CTR Viral Titles & Hooks
- Generate curiosity-inducing video titles and hooks designed for algorithmic CTR.

## How to Install in Developer Mode (Chrome / Edge / Brave)

1. Clone or download this repository:
```bash
git clone https://github.com/Mohdasif-07/ufftool-youtube-tags-extension.git
```
2. Open your Chromium browser and go to `chrome://extensions/` or `edge://extensions/`.
3. Enable Developer Mode (top-right toggle).
4. Click Load unpacked and select the extension directory.
5. Pin UffTool to your browser toolbar!
